# 整数加法 CLI：当前需求

这是当前产品行为的验收依据。运行入口是仓库根目录的 `add.py`，需要 Python 3.10+，只使用标准库。

- ADD-01：接受两个整数位置参数 `a`、`b`，支持负数和零，至少支持绝对值不超过 10^18 的输入；精确计算两数之和，结果允许超过 32 位整数范围。
- ADD-02：默认模式成功时，标准输出只包含和的十进制整数表示及一个换行；退出码为 0，标准错误为空。
- ADD-03：缺少参数、多余参数、非整数参数或未知选项时，退出码为 2，标准输出为空，标准错误包含非空诊断；不限定诊断措辞。`--help` 是标准帮助选项，不属于未知选项。
- ADD-04：允许从任意工作目录通过脚本的绝对路径执行；运行不需要网络或输入输出文件，不能在当前工作目录生成文件。

当前没有 `--absolute` 功能，也没有 ADD-05。它们是工作流练习的后续变更，不是当前版本已经实现的需求。
